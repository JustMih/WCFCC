Error Unable to write in the "/var/www/html/nidc/public/img/sliders" directory. 
Solution
sudo chmod 777 /var/www/html/nidc/app/Http/Controllers/ServiceApplicationController.php
sudo chown nginx:nginx /var/www/html/nidc/app/Http/Controllers/ServiceApplicationController.php

Confirm the Permissions and Ownership: Verify that the changes were applied:

ls -l /var/www/html/nidc/app/Http/Controllers/ServiceApplicationController.php

The output should now look something like this:

-rwxrwxrwx 1 nginx nginx 29027 Oct 21 11:49 /var/www/html/nidc/app/Http/Controllers/ServiceApplicationController.php

$ sudo chmod -R 775 /var/www/html/nidc/public/img/sliders
$ sudo chmod -R 777 /var/www/html/nidc/public/img/sliders

If SELinux is enabled, it can block write access even with correct permissions. To allow write access for the web server:

sudo chcon -R -t httpd_sys_rw_content_t /var/www/html/nidc/public/img/services/pdf

If you’re unsure about SELinux, check its status:

sestatus
If it's enabled and causing issues, the above command will fix it.

     charset utf-8;

 text/plain text/xsd text/xsl text/xml image/x-icon;

        location / {    try_files $uri $uri/ /index.php?$query_string;

        location ~ \.php {
                include fastcgi.conf;

$ sudo setenforce 0
